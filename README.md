# Data Engineering - A Yearly Learning Journey
## Introduction
This repo is the documentation of my structured journey to become a Data Engineer.
The purpose of this project is to develop a strong theoretical foundation and practical engineering skills through **systematic study, technical exercises, documentation, and independent projects**.

I believe in understanding the underlying concepts rather than simply learning tools and technologies.

## Learning Objectives

Throughout this journey, I aim to:

* Develop a strong understanding of database systems.

* Master SQL and relational database management.

* Develop programming proficiency in Python.

* Understand data architecture and data engineering principles.

* Learn to design and implement ETL pipelines.

* Develop practical experience with Linux, Git, APIs, and cloud technologies.

* Build independent data engineering projects.

## Learning Approach

My learning methodology follows four principles:

**Study**: Learn from textbooks, technical documentation, and other reliable resources.

**Document**: Record concepts and explanations in my own words.

**Practice**: Reinforce theoretical knowledge through practical implementation.

**Build**: Apply acquired knowledge to real-world projects.
