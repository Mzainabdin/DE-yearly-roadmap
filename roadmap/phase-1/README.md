# Phase I — Establish the Fundamentals

**Duration:** 3 Months

## 1. Introduction

Phase I establishes the foundational knowledge required for further study in Data Engineering.

The primary objective is to develop a strong understanding of database systems, relational database concepts, SQL, and Python programming.

Rather than rushing through technologies, this phase emphasizes conceptual understanding, practical implementation, and consistent technical documentation.

## 2. Learning Objectives

By the end of this phase, I aim to:

- Understand fundamental database concepts and database architectures.
- Understand relational database models and database design.
- Develop practical SQL querying skills.
- Understand tables, relationships, constraints, and normalization.
- Develop foundational Python programming skills.
- Understand programming logic, functions, data structures, and file handling.
- Build a habit of documenting technical knowledge.

## 3. Learning Resources

The following books form the primary learning resources for this phase:

1. Database System Concepts
2. Modern Database Management
3. Deciphering Data Architectures
4. Python Crash Course
5. Robust Python
6. Python for Geeks

Chapter assignments and practical exercises will be documented in the monthly study plans.

## 4. Monthly Structure

| Month | Focus |
|---|---|
| Month 1 | Database fundamentals and foundational SQL |
| Month 2 | Relational database design, SQL practice, and Python fundamentals |
| Month 3 | Database concepts consolidation, Python practice, and integration exercises |

## 5. Practical Work

Learning will be reinforced through:

- Designing relational database schemas.
- Creating data dictionaries.
- Writing SQL queries.
- Practicing database constraints and relationships.
- Solving Python programming exercises.
- Working with files and structured data.
- Documenting practical implementations.

## 6. Expected Outcomes

Upon completing Phase I, I should be able to:

- Explain fundamental database concepts.
- Design basic relational database schemas.
- Write SQL queries to retrieve and manipulate data.
- Understand database constraints and relationships.
- Write basic Python programs independently.
- Work with fundamental Python data structures.
- Maintain organized technical documentation.

## 7. Completion Criteria

Phase I will be considered complete when the assigned chapters, practical exercises, and required projects have been completed and reviewed.

The emphasis is on demonstrated understanding rather than merely checking off completed assignments.
