# Month 1 — Database Foundations and Python Basics

**Phase:** I — Establish the Fundamentals  
**Duration:** 30 Days

## 1. Monthly Objectives

Understand database systems, relational models, fundamental SQL and Python programming basics.

## 4. Monthly Checkpoint

By the end of Month 1, I should be able to:

- Understand basic relational database theory.
- Create relational tables.
- Write fundamental SQL queries.
- Write basic Python programs.

## 5. Monthly Assessment

The final assessment should evaluate both theoretical understanding and practical implementation.

The emphasis is on demonstrating independent understanding rather than simply completing the assigned chapters.
